# AussieBasket

A modern Australian e-commerce basket/shopping platform.

## Overview

AussieBasket is a shopping and basket management application tailored for the Australian market. It provides a seamless experience for browsing products, managing carts, and processing orders.

## Features

- Product browsing and search
- Shopping basket management
- Order processing and tracking
- Australian payment gateway integration
- User accounts and order history

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/saipatel/aussiebasket.git
cd aussiebasket
npm install
```

### Running Locally

```bash
npm run dev
```
